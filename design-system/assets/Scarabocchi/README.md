Segni a penna disegnati a mano (ref. 08): cerchio, sottolineatura, spunta, asterisco, freccia. Inchiostro fisso `cherry` (#de3e1e), tratto 3–4px con estremità arrotondate. Nell'interfaccia non si usano questi file ma le classi `ss-scribble--…` e `ss-mark--…` (colore `accent-text`, leggibile in ogni tema); i file servono per l'export e per disegnare nuovi segni con lo stesso tratto.
