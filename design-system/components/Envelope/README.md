# Envelope

La busta chiusa con ceralacca: quella kraft per la rivelazione, quella rosa (ref. 04) per i messaggi.

## Quando usarla
- Prima della rivelazione: la busta kraft "Per Giulia" sopra il bottone "Apri la busta"; è anche il fallback 2D e il riferimento per la busta 3D.
- La chat anonima: la busta rosa piccola "Psst…" (la busta di ref. 06) indica un nuovo messaggio dal tuo Babbo Natale.

## Cosa fornisci
`.ss-envelope` (`role="img"` con `aria-label`) con `.ss-envelope__seal` (ceralacca ciliegia con stella a 8 punte oro) e un `.ss-envelope__to` facoltativo. La larghezza si cambia inline; le proporzioni restano 26:17. Varianti: base `kraft`, `ss-envelope--rosa`.
