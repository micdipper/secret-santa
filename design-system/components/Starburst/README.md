# Starburst

Stella a raggiera da rivista (ref. 09): un solo numero grande dentro una stella senape con un'ombra rosa sfalsata.

## Quando usarla
- I giorni allo scambio in landing o in cima alla pagina del gruppo.
- Budget o numero di partecipanti, una volta.
- Mai più di una grande per schermata; `ss-burst--small` per un secondo dato.

## Cosa fornisci
`.ss-burst` con dentro un elemento che contiene `.ss-burst__value` (display, ≤4 caratteri) e `.ss-burst__label` (una parola). Testo `notte` sulla senape (10,5:1), oppure `fir` sulla variante `ss-burst--ghiaccio`. La stella è già inclinata con `tilt-strong`.
