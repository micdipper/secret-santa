# Secret Santa design system: source files

The published design system is at https://claude.ai/artifact/37c4HDEiqVqC1eyhSLxzRi (private until shared).

- `tokens.json`: colours (themes Carta/`light` and Abete/`dark`), type, spacing, radius, shadow and tilt tokens.
- `components/bundle.css`: the `ss-` component classes. It expects the tokens as CSS custom properties (`--fir`, `--surface`, `--space-4`, …).
- `components/<Name>/`: usage guidelines and a static preview for each component.
- `fonts/Basteleur-Bold.woff2`: display face (Velvetyne, SIL OFL). Bricolage Grotesque comes from Google Fonts.
- `assets/Ornaments/`: original SVG ornaments.

Extracted from `CLAUDE.md` and `reference/13-prova-vibe-nordica.png` on branch `claude/confident-sagan-im9axa`.
